# Bikash Talukder | Portfolio

A personal portfolio built for Bikash Talukder, showcasing projects, skills, research, and integrating a custom AI assistant (Nexora).

## Tech Stack
- **Core:** HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Accents:** Gold & Purple cinematic accents
- **Integrations:**
  - OpenWeatherMap API for live weather
  - GitHub API for public repositories
  - LeetCode API & Codeforces API for live coding metrics
  - Anthropic Claude API for the Nexora chatbot brain

## Project Structure
- `index.html` - The main entrypoint markup
- `style.css` - Centralized styling (responsive layouts, custom variables, glassmorphism animations)
- `package.json` - Local development configuration with Vite
- `.gitignore` - Standard files to ignore in Git

## Getting Started

### Local Development
To run a local development server with hot-reloading:
```bash
npm install
npm run dev
```

### Production Build
To bundle the portfolio for hosting:
```bash
npm run build
```
The output files will be built into the `dist/` directory.
